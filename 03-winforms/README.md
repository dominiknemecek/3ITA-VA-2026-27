# 03 — WinForms

První desktopová okenní aplikace. WinForms je starší, ale pořád hojně
používaný framework — okno se skládá z ovládacích prvků (tlačítko, textové
pole, popisek, ...), které mají vlastnosti a reagují na události (klik,
změna textu).

> **Pouze Windows.** WinForms aplikace se dají otevřít a spustit jen ve
> Visual Studiu na Windows — na macOS ani Linuxu je spustit nejde.

## Co byste měli umět po této kapitole

- Rozdíl mezi `Form1.Designer.cs` (vygenerovaný kód rozložení okna — needit)
  a `Form1.cs` (vlastní logika — sem se píše kód).
- Přidat na okno ovládací prvek a reagovat na jeho událost (např. klik na
  tlačítko).
- Číst a nastavovat vlastnosti prvků (`.Text`, `.Enabled`, ...) z kódu.
