# 02 — Objektově orientované programování

Základy OOP v C#: jak si navrhnout vlastní třídu, co je zapouzdření a jak
funguje dědičnost.

## Co byste měli umět po této kapitole

- Navrhnout vlastní třídu s poli, vlastnostmi (`property`), konstruktorem
  a metodami.
- Vysvětlit a použít zapouzdření (`private` pole + veřejná `property`
  s kontrolou hodnoty).
- Vytvořit hierarchii tříd přes dědičnost (`: base`) a přepsat metodu
  (`virtual` / `override`).
- Definovat a implementovat rozhraní (`interface`) a vysvětlit rozdíl
  oproti dědičnosti.
- Ošetřit chybu pomocí `try`/`catch`/`finally` a napsat vlastní výjimku.
