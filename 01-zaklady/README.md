# 01 — Základy jazyka C#

Úplné základy: co je proměnná, jaké datové typy C# nabízí, jak se čte vstup
od uživatele a jak se program větví a opakuje.

## Co byste měli umět po této kapitole

- Deklarovat proměnnou a vybrat jí vhodný datový typ (`int`, `double`,
  `string`, `bool`, ...).
- Načíst vstup z konzole (`Console.ReadLine()`) a bezpečně ho převést na
  číslo.
- Používat podmínky `if` / `else if` / `else` a `switch`.
- Používat cykly `for`, `while` a `foreach` a vědět, kdy který použít.
- Pracovat s polem (`int[]`) a s textovým řetězcem (`string`) — projít ho
  cyklem, rozdělit, upravit.
